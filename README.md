# RAG-Powered-Personalized-Career-Coach
 RAG Career Hub is a local Streamlit app using Ollama (Llama 3.2) &amp; ChromaDB. It parses resume PDFs to find skill gaps, build 30-60-90 day roadmaps, map job roles, and run interactive mock interviews with real-time scoring. 100% private, secure, and run completely on your local machin
